# Todo App
A full stack task management application built using NEXT.js , React js, TypeScript, Nodejs, Express js, Mysql

# features 
1. Add a new Task
2. View all task
3. update task title
4. Delete  a task
5. Input validation for empty task titles
6. Loading state
7. Error Handling
8. Basic style


# Technology used
## Frontend 
1. Next js
2. React js
3. Typescript

## Backend
1. Node js
2. Express js

# Database
1. MySql

## The backend is responsible for

1. Handling Api request
